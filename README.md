# Sistema de Controle de Estacionamento

Sistema de controle de estacionamento que registra informações como placa do veículo e quantidade de horas de permanência. O sistema também permite listar, buscar e registrar a saída dos veículos estacionados.

## Funcionalidades
- Registrar entrada de veículos
- Listar veículos
- Buscar veículos 
- Registrar saida
- Relatório

## Tecnologias utilizadas
- python 3  

## Conceitos utilizados
- Variáveis
- Listas
- Dicionários
- Funções
- Estruturas condicionais
- Laços de repetição
- Tratamento de erros com try/except

# como executar
1. Clone este repositório
2. Acesse a pasta do projeto
3. Execute:

```bash
python3 estacionamento.py
```
